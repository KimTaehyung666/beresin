# Beresin

**Beresin** adalah everyday utility toolkit tanpa login untuk hal-hal kecil yang sering bikin ribet. Semua proses berjalan di browser dan checklist disimpan di localStorage.

## Tools

Split Bill, Kalkulator Diskon, Kalkulator Cicilan, QR Generator, Password Generator, Pomodoro, Checklist, dan Konverter Satuan.

## Jalankan lokal

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Project ini cocok di-push ke GitHub lalu di-import ke Vercel sebagai project Vite. Tidak membutuhkan environment variable.
